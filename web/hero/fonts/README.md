# Fonts

The Figma design uses two typefaces. Drop the files below into this
folder and the page picks them up automatically (see the `@font-face`
rules in `../index.html`). Until then it falls back to Archivo/Inter
from Google Fonts.

## Overused Grotesk — free (SIL Open Font License)

Download from https://github.com/RandomMaerks/Overused-Grotesk
(`fonts/webfonts` folder in the repo) and place here as:

- `OverusedGrotesk-SemiBold.woff2`
- `OverusedGrotesk-Bold.woff2`

## Owners — commercial (Fenotype)

The headline font. Two options:

1. **Adobe Fonts** (included in Creative Cloud): create a Web Project
   with Owners Medium and paste the provided `<link>` tag into
   `index.html`, then change `--font-display` to the family name Adobe
   gives you.
2. **Webfont license** from the foundry: place the file here as
   `Owners-Medium.woff2`.

The `OwnersTRIAL` files used inside Figma are trial-licensed — don't
ship them on a public site.
